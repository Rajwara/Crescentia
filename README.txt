Crumb Bakery local copy
Source: https://crumb-bakery.webflow.io/

Extract the entire ZIP, then open index.html in Chrome or Edge.

To use a local server instead, open a terminal in the
extracted Crumb-Bakery folder and run one of these commands:

  Windows: py -m http.server 8000 --bind 127.0.0.1
  macOS or Linux: python3 -m http.server 8000 --bind 127.0.0.1

Open http://localhost:8000/ in your browser. Press Ctrl+C in the terminal
to stop the server. Keep the assets and menu folders next to index.html.

This is a static copy of the published site. The local order form shows
a preview message and does not transmit submissions. External links
still open their original destinations.
